How to use these guides

Solar planning is a chain of decisions. If you start with real daily energy use, the rest of the system falls into place more easily.

Each section is designed to answer one clear question, then link you to the next step. Use the calculators to sanity-check numbers before you price hardware.

If you are new, start with solar basics and sizing. If you already own a system, go straight to maintenance and troubleshooting.

If you are comparing options, the comparisons section is a fast way to see tradeoffs without marketing hype.

For budgeting, start with the cost breakdowns and adjust the system size until it matches your real use.

Use the header navigation to jump between categories as your questions change.

Start with your load list

List daily watt-hours first. It keeps panel and battery choices grounded. Guessing at loads usually inflates cost and leads to oversized systems.

Pick a realistic system size

Use the sizing guide to define a target, then decide whether you want daily solar coverage or a backup generator for cloudy weeks.

Keep wiring and safety visible

Wiring, protection, and disconnects are not optional. The wiring guides show how to avoid voltage drop, overheating, and hard-to-service layouts.
