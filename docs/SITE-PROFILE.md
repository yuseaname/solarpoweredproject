# Site Profile: solarpoweredproject.com

## Overview
Solar education and buying guide site targeting US homeowners considering solar energy. Covers system sizing, cost analysis, component selection, and DIY installation topics.

## Content
- **76 article pages** — Solar panel guides, cost breakdowns, system sizing, component comparisons
- **18 DIY off-grid energy guides** — Alternative energy projects (micro-hydro, wind, thermoelectric, etc.)
- **2 state-specific guides** — Solar battery cost (2026), solar panel cost California
- **Homepage** — Hub linking to all major content sections

## Monetization
- Google AdSense (display ads)

## Target Audience
- US homeowners researching solar energy
- DIY solar/off-grid enthusiasts
- People comparing solar costs, components, and installation options

## SEO Strategy
- Long-form informational content targeting solar-related search queries
- Sitemap auto-generated from all pages during build
- Static HTML for fast load times

## Technical Stack
- Pure static HTML/CSS/JS (no framework)
- No build dependencies — shell script copies files to output directory
- Hosted on Hostinger via rsync
- Deployed via GitHub Actions on push to main
